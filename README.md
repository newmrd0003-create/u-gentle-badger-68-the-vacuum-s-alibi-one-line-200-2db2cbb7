# The Vacuum's Alibi

One-line entry for the make.fun competition "The Vacuum's Alibi": a vacuum cleaner refuses to work overtime — that spot is scheduled for Thursday, and today is Tuesday.

> That spot is scheduled for Thursday. Today is Tuesday. I do not do overtime.

## How it works

`main.py` (Python stdlib only, no network) writes the 76-character entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), with no trailing newline, and verifies the output by reading it back and asserting the exact length.
